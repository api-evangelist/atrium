# Atrium

> Atrium is a sales-effectiveness and sales-performance analytics platform for revenue
> teams: it monitors sales KPIs, surfaces anomalies in rep and team performance, and
> delivers coaching recommendations to managers. Atrium was acquired by Fullcast in 2025
> and now ships as **Fullcast Performance**. Atrium has **no public developer API** — it
> integrates into Salesforce, HubSpot, data warehouses and communication tools rather than
> exposing one. This file is generated by API Evangelist from a third-party profile;
> Atrium does not serve an llms.txt of its own (every path on atriumhq.com returns HTTP 301
> to the acquirer's product page).

## Status

- Brand status: absorbed by acquirer. atriumhq.com 301s to https://www.fullcast.com/product/fullcast-performance/
- Only surviving Atrium host: https://app.atriumhq.com/auth/login (customer application login, not an API)
- No API host, docs host or developer portal resolves on atriumhq.com
